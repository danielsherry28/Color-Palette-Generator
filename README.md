# Hue & Form

A responsive, single-page color discovery quiz and personal palette experience. It starts with a welcoming introduction, asks seven short questions, then recommends a color story with five named swatches, copyable hex values, and styling inspiration.

## Run locally

Open `index.html` in a modern browser. There are no build tools or dependencies. Google Fonts are loaded from the web; system serif and sans-serif fallbacks are included.

## Project files

- `index.html` — page structure and accessible controls
- `styles.css` — responsive styling and motion preferences
- `app.js` — quiz flow, palette matching, and copy interactions
